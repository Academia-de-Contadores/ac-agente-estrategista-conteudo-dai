# Contribuindo

Crie uma branch a partir de `main`, classifique a mudança no pull request e
descreva impacto, riscos e avaliações executadas. Mudanças comportamentais devem
incluir ou atualizar avaliação de regressão. Áreas críticas exigem aprovação do
owner definido em `CODEOWNERS`. Use squash merge e não faça push direto em `main`.
